# ShowClock: download

Show alarm for the Burj Khalifa LED screen control room. Dubai time, what plays next, and alarms for every
pre-show, show start and red timecode item, set automatically from the monthly schedule.

**[Download for Windows](https://github.com/JunaidParamberi/showclock-download/releases/latest/download/ShowClock-Setup.exe)** (about 120 MB)
· **[Open the web app](https://saco-showclock.vercel.app)**

## Install
1. Run `ShowClock-Setup.exe`. Windows may say "Windows protected your PC": click **More info → Run anyway**
   (the app is not code-signed yet).
2. ShowClock opens full screen and starts with Windows.
3. Go to **Schedule → Upload** and pick the month's Excel sheet. The cell colours set the type.
4. In Windows settings: **Set time automatically** on, and the PC set to never sleep.

This repository only holds the installer. It contains no schedule data.
